# week2 Introduction to Web Design
## ให้นักศึกษา ออกแบบเว็บไซต์ แนะนำสถานที่ท่องเที่ยวในจังหวัดเชียงใหม่ สำหรับนักท่องเที่ยว
1.วิเคราะห์วัตถุประสงค์และกลุ่มเป้าหมายของเว็บไซต์
วัตถุประสงค์ของเว็บไซต์ : วัฒนธรรม อาหาร และที่พัก เพื่อช่วยให้นักท่องเที่ยวตัดสินใจเลือกจุดหมายปลายทางได้ง่ายขึ้นและกระตุ้นเศรษฐกิจและการท่องเที่ยว
กลุ่มเป้าหมายหลัก : นักท่องเที่ยวต่างชาติ นักท่องเที่ยวไทยที่อยากมาท่องเที่ยวในจังหวัดเชียงใหม่

4.อธิบายเหตุผลในการเลือกสี การจัดวาง และการออกแบบ : สีน้ำตาลสื่อถึงธรรมชาติ ภูเขา ดิน ไม้ และความอบอุ่นของวัฒนธรรมล้านนาและสีขาวสะอาดตาช่วยสร้างพื้นที่ว่างทำให้ตัวอักษรอ่านง่าย
เหตุผลในการจัดวางองค์ประกอบ: ฝั่งซ้ายเป็นตำแหน่งโลโก้ ชื่อเว็บไซต์ คำอธิบาย และปุ่มเริ่มต้นไว้ด้วยกัน ทำให้ผู้เข้าชมเข้าใจทันทีตั้งแต่ว่าเว็บไซต์นี้เกี่ยวกับอะไร ฝั่งขวาแยกแถบเมนูไว้ด้านบนสุดเพื่อให้ง่ายต่อการคลิกเปลี่ยนหน้า และจัดพื้นที่ขนาดใหญ่ตรงกลางสำหรับโชว์ภาพบรรยากาศ เพื่อดึงดูดอารมณ์ให้อยากออกเดินทางมากขึ้น เน้นภาพนำเรื่องและเรียบง่ายให้ดูน่าสนใจสำหรับผู้เข้าชมเว็บไซต์
