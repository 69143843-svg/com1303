# com1303
1.Git คืออะไร
คือระบบบันทึกประวัติการแก้ไขไฟล์ที่ช่วยติดตามทุกการเปลี่ยนแปลงของโค้ด สามารถย้อนกลับไปดูเวอร์ชันเก่าเมื่อเกิดข้อผิดพลาด รองรับการทำงานร่วมกันในทีมโดยไม่ให้ไฟล์ทับกัน และเปิดโอกาสให้แยกกิ่งไปทดลองทำระบบใหม่ๆ โดยไม่กระทบกับโค้ดหลัก
2.การทำงานของเว็บไซต์ทำงานอย่างไร
กระบวนการรับ-ส่งข้อมูลระหว่าง Client เบราว์เซอร์ของเรา กับ Server ผ่านอินเทอร์เน็ต
3.เว็บไซต์ต่างจากเว็บแอพพลิเคชั่น อย่างไร
เว็บไซต์ เน้นแสดงข้อมูลให้อ่านเป็นหลัก เช่น เว็บข่าว บล็อก หรือเว็บแนะนำบริษัท
เว็บแอปพลิเคชัน เน้นให้ผู้ใช้งานโต้ตอบและทำกิจกรรมซับซ้อนได้ เช่น ระบบสร้างเอกสาร โซเชียลมีเดีย หรือแอปทำธุรกรรมทางการเงิน
4.ให้สร้างคู่มือการใช้งาน Github
สิ่งที่ต้องเตรียมก่อนเริ่ม
ติดตั้งโปรแกรม: โหลดและติดตั้งแอป GitHub Desktop ลงคอมพิวเตอร์ แล้วล็อกอินด้วยบัญชี GitHub ของคุณ
เตรียมไฟล์งาน: สร้างโฟลเดอร์งานในคอมพิวเตอร์ โดยภายในต้องมีไฟล์ index.html คือไฟล์โครงสร้างเว็บหลัก
ขั้นตอนที่ 1: เข้าไปที่หน้า Repository ของคุณบน GitHub
กดปุ่ม Add file แล้วเลือก Create new file
ในช่องตั้งชื่อไฟล์ ให้พิมพ์ว่า README.md
พิมพ์เนื้อหาอธิบายงานลงในช่องว่างด้านล่าง
เมื่อเขียนเสร็จแล้ว กดปุ่มสีเขียว Commit changes มุมขวาบน และกด Commit changes อีกครั้งเพื่อบันทึก
ขั้นตอนที่ 2: สัญลักษณ์พื้นฐานในการแต่งข้อความ
ไฟล์ .md ใช้ภาษา Markdown ในการจัดรูปแบบข้อความ ลองนำสัญลักษณ์เหล่านี้ไปปรับใช้ได้สร้างหัวข้อใหญ่: ใส่เครื่องหมาย # แล้วเว้นวรรค
เน้นตัวหนา: ใส่เครื่องหมาย ** ล้อมรอบข้อความ
สร้างรายการสัญลักษณ์ (Bullet Points): ใส่เครื่องหมาย * หรือ - แล้วเว้นวรรค เช่น * รายการที่ 1
ทำเส้นคั่นแบ่งหมวดหมู่: พิมพ์เครื่องหมาย - ติดกัน 3 ตัวขึ้นไป เช่น ---
