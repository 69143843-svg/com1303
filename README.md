1.วิเคราะห์วัตถุประสงค์และกลุ่มเป้าหมายของเว็บไซต์
วัตถุประสงค์ของเว็บไซต์ : วัฒนธรรม อาหาร และที่พัก เพื่อช่วยให้นักท่องเที่ยวตัดสินใจเลือกจุดหมายปลายทางได้ง่ายขึ้นและกระตุ้นเศรษฐกิจและการท่องเที่ยว
