# com1303
1.Git คืออะไร
คือระบบบันทึกประวัติการแก้ไขไฟล์ที่ช่วยติดตามทุกการเปลี่ยนแปลงของโค้ด สามารถย้อนกลับไปดูเวอร์ชันเก่าเมื่อเกิดข้อผิดพลาด รองรับการทำงานร่วมกันในทีมโดยไม่ให้ไฟล์ทับกัน และเปิดโอกาสให้แยกกิ่งไปทดลองทำระบบใหม่ๆ โดยไม่กระทบกับโค้ดหลัก
2.การทำงานของเว็บไซต์ทำงานอย่างไร
กระบวนการรับ-ส่งข้อมูลระหว่าง Client เบราว์เซอร์ของเรา กับ Server ผ่านอินเทอร์เน็ต
3.เว็บไซต์ต่างจากเว็บแอพพลิเคชั่น อย่างไร
เว็บไซต์ เน้นแสดงข้อมูลให้อ่านเป็นหลัก เช่น เว็บข่าว บล็อก หรือเว็บแนะนำบริษัท
เว็บแอปพลิเคชัน เน้นให้ผู้ใช้งานโต้ตอบและทำกิจกรรมซับซ้อนได้ เช่น ระบบสร้างเอกสาร โซเชียลมีเดีย หรือแอปทำธุรกรรมทางการเงิน
4.ให้สร้างคู่มือการใช้งาน Github
ขั้นตอนที่ 1: สร้างพื้นที่เก็บงานบน GitHub
ล็อกอินเข้าเว็บ GitHub
กดปุ่มสีเขียว New สามารถกดเครื่องหมาย + มุมขวาบน
ตั้งชื่อโปรเจกต์ในช่อง Repository name 
เลือก Public เพื่อให้คนอื่นเข้ามาดูได้
ติ๊กถูกที่ Add a README file เอาไว้เขียนอธิบายงาน
กดปุ่มสีเขียว Create repository ด้านล่างสุด
ขั้นตอนที่ 2: วิธีส่งลิงก์งานให้คนอื่นดู
คัดลอก URL จากแถบที่อยู่ด้านบนของเบราว์เซอร์ (เช่น [google](https://www.google.com/)
